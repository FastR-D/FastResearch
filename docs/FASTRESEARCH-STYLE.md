# FastResearch 科研协同工作台视觉规范

## 产品定位与气质

FastResearch 是面向学者的研究协同工作台：温和、严谨、秩序分明、信息密度适中。
整体视觉去除浮夸的“AI 科技感/科幻暗色终端”套路（如炫光外晕、虚假假进度启动屏、光标跟随粒子），转而呈现真正服务于科研阅读、论证与实验的学术质感：
1. **真实科研质感**：如同学术手稿与实验记录本般的雅致浅绿底色，细密微弱的实验坐标网格线，搭配纯白学术卡片与清晰的层级边框。
2. **克制温润的色调**：以天然冷杉深绿（Spruce Pine `#155e45`）为主色，浅茶绿/鼠尾草绿（`#f0f5f2`）为背景，保证长时间阅读文献与撰写论文时的视觉舒适度。
3. **低干扰、高敏捷**：无人工延迟启动界面，即开即用；文字、排版、状态流、文献卡片清晰直观。

## 色彩规范

- **全局浅绿底色**：`#f0f5f2`，辅以柔和微弱的径向绿晕（`#deede3`）。
- **学术网格纹理**：`rgba(21, 94, 69, 0.04)` 细线网格（32px 间隔），提供严谨的实验记录本纸质感。
- **主交互色 (Forest Green)**：`#155e45`，悬停 `#104936`，浅色底衬 `#e8f3ed`。
- **卡片表面 (Surface)**：纯白 `#ffffff`，辅助浅灰色 `#f8faf8`。
- **边框规范**：`#d6e3db`，高亮激活态 `#8fb9a0`。
- **文本颜色**：深岩深森林绿 `#172720`（高可读性），次要说明 `#567265`，元数据 `#7f998d`。
- **模块工序色调**：
  - FastPPT（汇报）：玫瑰茜红 `#9f1239`
  - FastWrite（写作）：墨紫 `#4338ca`
  - FastRead（研读）：青松蓝绿 `#0f766e`
  - FastNews（前沿）：琥珀暖棕 `#b45309`
  - FastLab（实验）：翡翠绿 `#15803d`

## 排版系统

- **界面字体**：`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Noto Sans SC`, `PingFang SC`, sans-serif。
- **状态、编号、DOI、时间戳**：`JetBrains Mono`, `SF Mono`, Consolas, monospace。
- **标题**：22px–44px，字重 600–700，字距微收（-0.02em ~ -0.03em）。
- **正文**：13px–14px，行高 1.65–1.75，保障学术段落阅读体验。

## 布局与组件

1. **顶部导航 (64px)**：
   - 品牌：烧瓶微标 + `FastResearch` + `科研工作台` 标识。
   - 状态：`科研工作流协同中` 实时脉冲灯。
   - 凭证入口：个人科研 Key 认证按钮、主题切换、后台凭证管理。
2. **主面板 (双栏工序流水线)**：
   - 左侧工序导航：01–05 阶段列表，标明当前工序与完成勾选。
   - 右侧工作区：展示当前阶段任务说明、进入外部工作区按钮与流转下一步按钮。
3. **FastInsight 学术信箱**：
   - 飞书自动推送卡片分拣列表，右侧采用规范的学术预印本布局（作者、收录期刊、论文核心摘要、趋势分析与查看原文）。
4. **科研凭证弹窗**：
   - 采用温和白底绿边框卡片，毛玻璃半透明遮罩，交互利落。
