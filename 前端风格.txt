# 使用说明

本规范将 BlockSec 首页的视觉语言沉淀为 FastResearch 的统一前端基线。它适用于工作台、流程面板、文献洞察、认证弹窗和管理界面。产品保持蓝色主色，所有页面都应呈现可信、清晰、克制的 Web3 安全工具气质。

## 视觉定位

- 关键词：安全、专业、轻量、数据密集、可扫描。
- 结构：宽内容容器、清晰导航、分区面板、少量卡片化重点信息。
- 质感：浅灰页面底色配白色面板，使用 1px 细边框和柔和阴影建立层级。
- 重点：蓝色只用于品牌、主操作、状态和当前步骤；不要让整页变成高饱和蓝色。
- 参考页面的橙色强调统一替换为蓝色和浅青色，以满足 FastResearch 的品牌要求。

### 颜色使用

- 页面底色固定为 `#f6f6f9`，避免纯白大面积铺满。
- 面板使用 `#ffffff`，通过边框或阴影与页面底色分离。
- 主按钮、链接、进度条、当前步骤使用 `#2f8af5`；高风险或强提醒才使用深蓝 `#004ab2`。
- 主文字使用 `#101820`，正文和说明使用 `#475467` / `#697586`。
- 浅蓝底只承载选中、提示、身份和状态，不作为整页背景。
- 不使用绿色作为品牌强调色，不使用橙色作为 CTA，不使用紫色渐变。

## 字体与排版

```text
界面字体: -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans SC",
           "PingFang SC", "Microsoft YaHei", sans-serif
等宽字体: "JetBrains Mono", "SF Mono", Consolas, monospace
```

- 页面正文：14–16px，行高 1.55–1.7。
- 辅助说明：12–14px，行高 1.45–1.6。
- 页面主标题：40–64px，字重 700，移动端 30–36px。
- 区块标题：24–40px，字重 700；面板标题：16–20px，字重 600。
- 标签、状态、编号可以使用等宽字体或 11–12px 的紧凑字级。
- 标题采用自然字距，不使用大幅负字距；正文必须保持可读性。

## 页面骨架

### 顶部导航

- 桌面端高度约 80px，移动端高度 56px。
- 导航保持 sticky 或 fixed，背景为半透明白色并配轻微毛玻璃；滚动后可加强底边框和阴影。
- 左侧品牌标识由图形、`FastResearch` 和短副标题组成；品牌蓝色为 `#004ab2`。
- 桌面端导航项使用 14–16px 中等字重；当前项通过蓝色文字和底部 3–4px 指示条表示。
- 右侧放置身份、主题、语言和管理入口；图标按钮使用 34–40px 稳定尺寸。
- 移动端隐藏次要导航，只保留品牌和菜单按钮，不让导航横向溢出。

### 主内容

- 最大宽度约 1200px，桌面端左右留白 32–60px，移动端 16–24px。
- 区块上下间距 56–120px；相关内容用 24–40px 间距分组。
- 复杂工作流采用“左侧步骤栏 + 右侧当前工作区”；宽度不足时步骤栏移到上方并横向滚动。
- 页面第一屏直接展示工作流和下一步操作，不使用营销式 Hero 卡片。

### 信息层级

1. 页面标题和当前任务。
2. 当前状态、进度和关键指标。
3. 当前阶段说明与主操作。
4. 辅助信息、日志、文献详情和管理入口。

## 面板与卡片

- 标准面板：白底、`border: 1px solid #e4e7ec`、圆角 16px、阴影 `0 12px 36px rgba(16,24,40,.08)`。
- 紧凑卡片：白底、1px 边框、圆角 10–12px、阴影 `0 4px 12px rgba(16,24,40,.06)`。
- 内部次级区域使用 `#f8fafc` 或 `#e8f3ff`，不要嵌套过多浮动卡片。
- 卡片内边距：移动端 16–20px，桌面端 24–32px。
- 边框保持 1px；不要使用粗重边框、硬描边或拟物双阴影。
- 图标可放在浅蓝圆角方块或白色圆形底中，尺寸应稳定，避免装饰性图形抢夺信息焦点。

## 按钮与交互

### 主按钮

```css
background: #2f8af5;
color: #ffffff;
border: 1px solid #2f8af5;
border-radius: 8px;
box-shadow: 0 4px 12px rgba(47, 138, 245, .18);
```

- 高度 40–48px，水平内边距 16–24px，字重 600。
- Hover：背景变为 `#1769d3`，阴影略增强；Active：背景变为 `#004ab2`。
- Disabled：透明度约 0.48，禁止改变尺寸或产生位移。

### 次按钮

- 白底、1px `#d0d5dd` 边框、深蓝文字、圆角 8px。
- Hover 使用 `#e8f3ff` 背景和 `#2f8af5` 边框；Active 使用浅蓝内阴影或更深文字。
- 文本按钮只用于低风险次要动作，不能代替主要 CTA。

### 输入框

- 白底、1px `#d0d5dd` 边框、圆角 8–10px，高度 40–48px。
- Focus 使用 `#2f8af5` 边框和 `0 0 0 3px rgba(47,138,245,.16)` 外环。
- Placeholder 使用 `#98a2b3`；错误状态使用 `#d92d20` 边框和明确文案。
- 输入框不能使用拟物内阴影，也不能在 focus 时放大或移动。

### 反馈

- Hover 通过颜色、边框、阴影或透明度变化反馈，不使用明显位移。
- 过渡统一 `150–250ms ease`；复杂面板展开使用 `250–350ms`。
- 加载、完成、锁定、未读状态应同时有颜色、图标和文字，不只依赖颜色。

## 工作流组件

- 工作流外壳使用白色面板和细边框；标题栏显示区块名、完成数和辅助动作。
- 左侧步骤栏底色 `#f8fafc`，当前步骤使用 `#e8f3ff` 背景、`#2f8af5` 左侧指示条和深蓝文字。
- 已完成步骤使用蓝色勾选；待处理步骤使用低对比度灰色；锁定步骤显示锁图标和说明。
- 进度条轨道为 `#e4e7ec`，进度为 `#2f8af5`，高度 6–8px，圆角全圆。
- 当前工作区的主操作放在右下或内容末尾，主按钮只有一个。
- 不同模块只通过蓝色深浅、图标和标签区分，不再使用蓝绿紫橙多色主题。

## 洞察与文献卡片

- 列表行使用白底和 1px 浅边框，Hover 变为 `#f8fafc`，当前行使用 `#e8f3ff`。
- 未读点使用 `#2f8af5`，同时提供未读文字或数量。
- 论文标题最多两行，作者、来源、时间使用 12–13px 次级文字。
- 摘要和趋势分析放在 `#f8fafc` 次级区域中，避免大段文字直接贴在白底上。
- 外部链接使用蓝色文字和箭头图标，点击区域至少 40px 高。

## 弹窗与认证

- 遮罩使用 `rgba(16,24,32,.36)`，不使用纯黑。
- 弹窗白底、圆角 16px、阴影 `0 24px 64px rgba(16,24,40,.18)`，桌面宽度 420–680px，移动端不超出视口。
- 标题、说明、表单、错误信息、主操作按垂直节奏排列；关闭按钮为图标按钮并有 aria-label。
- 凭证、Key、URL 等敏感信息使用等宽字体，并提供复制、撤销或重新生成后的明确反馈。

## 响应式规则

- 断点：`600px` 处理手机布局，`960px` 处理平板/窄桌面，`1200px` 处理内容最大宽度。
- 小于 960px：双栏工作流改为单栏，步骤栏移到工作区顶部并允许横向滚动。
- 小于 600px：导航压缩到 56px，按钮可占满一行，面板内边距降到 16–20px。
- 所有固定格式区域使用 `min-width: 0`、`max-width: 100%` 和稳定高度，禁止页面横向滚动。
- 文字不得遮挡按钮、图标或相邻区块；长 URL、标题和人员名称必须截断或换行。

## 无障碍与质量

- 正文与背景对比度至少达到 WCAG 2.1 AA；蓝色按钮上的白字必须保持清晰。
- 所有图标按钮提供 `aria-label` 和 tooltip；键盘焦点使用可见蓝色外环。
- 不能只通过颜色表达状态；状态至少同时有图标、文字或形状变化。
- 支持 `prefers-reduced-motion: reduce`，减少动画和滚动行为。
- 提交前检查桌面 1440px、平板 768px、手机 390px 三种视口。

## 禁止项

- 禁止新拟物双光源阴影、纯黑/纯白整页背景、粗边框和硬描边。
- 禁止大面积橙色、绿色、紫色或渐变作为品牌色；橙色不得出现在主要 CTA。
- 禁止使用 `translate` 制造按钮按下位移、悬浮卡片漂移或布局跳动。
- 禁止在卡片中继续堆叠无意义的卡片；禁止营销式大 Hero 取代实际工作区。
- 禁止固定宽度导致横向滚动；禁止使用低对比度小字承载关键操作。
